# IsotopeMultiMixer.java

## 概要

1つの水源A（単一）と複数の水源B（配列）を混合する多対多同位体混合コンポーネントです。  
Aの体積をBの各要素の体積比に応じて重み付けして分配し、各BとAの混合濃度を計算します。

## 科学的背景

流域モデルにおいて、1つの上流貯留層（例：降水または土壌水）から複数の下流セルへ水が流れる場合、  
各セルへの貢献は体積に比例すると仮定して同位体濃度を配分します。  
これにより空間的に分布した水文モデルでの同位体輸送が表現できます。

---

## 入力変数

| 変数名 | 単位 | 説明 |
|--------|------|------|
| `volA` | L | 水源Aの体積（単一値） |
| `volB[]` | L | 水源Bの体積配列（複数セル） |

---

## 入出力変数（READWRITE）

| 変数名 | 単位 | 説明 |
|--------|------|------|
| `concA` | ‰ | 水源Aの同位体濃度（混合後に加重平均で更新） |
| `concB[]` | ‰ | 水源Bの同位体濃度配列（各セルで混合後に更新） |

---

## 計算ロジック（runメソッド）

### 1. Bの総体積を計算
```
volume = Σ volB[i]
```

### 2. 各セル i について混合濃度を計算

#### a. Bの体積重みを計算（全B体積に対する割合）
```
weight[i] = volB[i] / volume
```

#### b. AのうちB[i]に割り当てる実効体積を計算
```
volA_weighted = volA × weight[i]
```

#### c. 混合後濃度 x を計算
```
if (volA + volB[i] == 0 または volume == 0):
    x = 0
else:
    x = (concA × volA_weighted + concB[i] × volB[i]) / (volA_weighted + volB[i])
```

#### d. Bの濃度を更新
```
concB[i] = x
```

#### e. Aの加重平均濃度を累積
```
concSum += x × weight[i]
```

### 3. Aの濃度を更新
```
concA = concSum
```

## IsotopeMixer.java との違い

| 項目 | IsotopeMixer.java | IsotopeMultiMixer.java |
|------|-------------------|------------------------|
| 水源Aの形式 | 配列（各セル対） | 単一（全セルで共有） |
| 混合の方向 | A[i] ↔ B[i]（ペア） | A（単一） → B[i]（複数） |
| Aの体積分配 | なし（等価ペア） | 体積比で重み付け分配 |
| `bidirectional`フラグ | あり | なし（常に双方向更新） |
| `mixingProportion`パラメータ | あり | なし |

---

## 使用上の注意

- `volume == 0`（Bの総体積が0）の場合、濃度は全て 0 に設定されます。
- デバッグ用の `System.out.println` がコード内に残っています（本番環境では削除を推奨）。
- `concA` は各 `concB[i]` の体積加重平均として更新されます。
